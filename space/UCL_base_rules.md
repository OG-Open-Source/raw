### **UCL (Universal Control Language) 規則文件**

#### **核心設計哲學**

1.  **執行模型 (Execution Model)**

    - **同步執行**: 在單一語句或表達式內部，UCL 嚴格遵循**由左至右**的順序執行。
    - **異步任務排程**: 從整個檔案的宏觀角度來看，UCL 採用任務排程的方式**由上至下**執行。每個獨立的邏輯塊（如函式呼叫、迴圈等）被視為一個任務（Task），並依序排入佇列。

2.  **消除歧義 (Disambiguation)**

    - 藉由**符號唯一性**，確保一種符號組合只會有一個意思，但允許多種行為。

3.  **預先加載與延遲求值 (Pre-loading and Lazy Evaluation)**

    - UCL 的執行並非單純的由上至下。編譯器會先掃描並註冊所有宣告的種類（變量、常量等）及其型別和層次結構。
    - 內容的實際值（Value）只有在被引用或需要時才會被完全加載和計算。

4.  **型別安全與預防性保護 (Type Safety and Proactive Protection)**

    - **型別不變性**: 一旦一個實體（變量/常量）的型別被宣告，就無法再次變更。
    - **編譯期範圍檢查**: 為了系統穩定性，UCL 強制在編譯階段就定義好數值範圍。例如，一個 `:u008:` 型別的變量（範圍 0 到 255），任何試圖使其超出範圍的操作（如 `255 + 1`）都會在編譯時被攔截，而不是在執行時導致崩潰。

5.  **符號不可重複性 (Non-Repeatable Symbols)**
    - 為了維持語法的清晰和無歧義，UCL 中的運算子和符號不允許連續重複使用。
    - 每個運算子都應被視為一個獨立的原子操作。
    - **錯誤範例**: `!!!` (連續反向), `:=:=:=` (連續迭代賦值) 都是不合法的語法。

### **1. 語法與宣告**

- `常量 (Constant)`

  - 使用 `ABCDEFGHIJKLMNOPQRSTUVWXYZ1234567890_` 組合。
  - 以 `#...#` 作為宣告和引用的判斷依據。
  - 跨物件引用格式為 `#...:物件#`。
  - 常量一經賦值便不可更改。
  - **宣告與賦值範例：**
    ```ucl
    #CST# = :flo:       // 宣告一個允許浮點數的空常量
    #CST# = 1.23        // 賦值 CST 常量浮點數 1.23
    #CST# = 4.56        // Err: 常量不允許重複賦值
    #ENV_CST# = $API_KEY:.env$ // 從 .env 文件獲取 API_KEY 並宣告為常量
    ```
  - **常量宣告塊**：使用 `#(...)#` 進行批量宣告。
    ```ucl
    #(                  // 常量宣告塊
    	PI = ( Math.Pi(5) )      // PI 常量被賦值為 3.14159
    	E  = ( Math.E(5) )       // E 常量被賦值為 2.71828
    )#
    ```

- `變量 (Variable)`

  - 使用 `abcdefghijklmnopqrstuvwxyz1234567890_` 組合。
  - 以 `$..$` 作為宣告和引用的判斷依據。
  - 跨物件引用格式為 `$..:物件$`。
  - **宣告與賦值範例：**

    ```ucl
    // 宣告一個允許字串(str)或整數(int)的變量
    $var$ = :str|int:
    $var$ = "Hello"     // 合法賦值
    $var$ = 123         // 合法重新賦值
    $var$ = 3.14159     // Err: 使用了不允許的型別 :flo:
    $var$ = World       // Err: World 非字串或數字，被視為不存在的狀態

    $arr$ = :arr<ord|het|rep>: // 宣告一個可變、有序、多型別、可重複的陣列
    $arr$ = :arr<ord|het|rep>: // Err: 不可對同一變量重複宣告型別

    $file_name = @:a.json // 從 a.json 的獲取 name 鍵值，並宣告成變量
    ```

  - **變量宣告塊**：使用 `$(...)$` 進行批量宣告。
    ```ucl
    $(                  // 變量宣告塊
    	x = 123
    	y = 321
    )$
    ```
  - **快速型別宣告**: 可同時為多個變量和常量宣告相同的型別。
    ```ucl
    $var1$, $var2$, #CST1#, #CST2# = :str: // 將所有實體宣告為字串型別
    ```

- `物件 (Object)`

  - 使用 `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz1234567890` 組合。
  - 以 `_...` 表示。範例：`_Sys`

- `函式 (Function)`

  - 使用 `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz1234567890` 組合。
  - 直接以名稱表示。範例：`Text`

- `狀態 (State)`

  - `布林值 (Boolean)`: `true` 和 `false`。
  - `綱要 (Schema)`: 使用 `物件::...` 進行物件綱要。
  - **綱要宣告塊 (Schema Block)**：使用 `!(...)!` 創建複雜的綱要。
  - **狀態改寫 (State Override)**: 在綱要宣告塊內部，可以使用 `=>` 將一個值（如字串）映射到一個已宣告的綱要狀態。這使得外部回傳的原始值可以被強制轉換為內部使用的嚴格狀態。
    ```ucl
    !(
    	Arch(
    		x86
    		arm
    	)
    	_Sys{
    		Arch{
    			"x86" => Arch::x86 /* 將字串 "x86" 映射到狀態 Arch::x86 */
    			"arm" => Arch::arm
    		}
    	}
    )!
    ```

- `註解 (Comment)`: 以 `/* ... */` 使用，支援多行。

- `空值 (Null)`: 使用 `null` 表示，將不會被使用。

- `縮排 (Indent)`: 使用定位點（Tab）進行縮排。

### **2. 極度嚴格的強型別**

- **聯合型別 (Union Type)**: 使用 `|` 宣告一個變數可接受多種指定型別。
  - 參考：`$var$ = :str|int:` // 允許字串和整數
- `:any:` 為任意型別，僅用於特殊情況。
- `:txt:` 為文本
  - `:str:` 為字串，使用 Unicode，以 `"..."` 作判斷依據。
  - `:chr:` 為字元，使用 ASCII，以 `'...'` 作判斷依據。
- `:stu:` 為狀態，無需包裹（預設使用 `:bool:`）。
  - `:bool:` 為布林值，只有 `true` 和 `false`。
  - `:schm:` 為綱要，格式為 `物件::...`。
- `:num:` 為數字，無需包裹。
  - **整數 (Integer)**: 預設為 `:i064:`。
    | 型別 | 範圍 |
    |:---:|:---|
    | `:u008:` | 0 .. 255 |
    | `:i008:` | -128 .. 127 |
    | `:u016:` | 0 .. 65535 |
    | `:i016:` | -32768 .. 32767 |
    | `:u032:` | 0 .. 4294967295 |
    | `:i032:` | -2147483648 .. 2147483647 |
    | `:u064:` | 0 .. 18446744073709551615 |
    | `:i064:` | -9223372036854775808 .. 9223372036854775807 |
  - **浮點數 (Float)**: 預設為 `:f064:`。
    | 型別 | 範圍 |
    |:---:|:---|
    | `:f032:` | -3.4e+38 .. +3.4e+38 |
    | `:f064:` | -1.7e+308 .. +1.7e+308 |
- `:arr:` 為陣列，可選參數：有序(ord)/無序(uno)、同型別(hom)/多型別(het)、重複性(rep)/唯一性(uni)。（預設：ord|het|rep）。
  - **字面值語法**: 使用 `[...]` 賦值，**索引從 1 開始**。
  - ```ucl
    $arr$ = :arr<ord|het|rep>:        // 宣告陣列
    $arr$ = [2, 1, "Hello"]           // 賦值
    $arr$[#1]                         // 獲取第一項 (2)
    ```
- `:dic:` 為字典，可選參數：有序(ord)/無序(uno)、同型別(hom)/多型別(het)。（預設：uno|het）。
  - **字面值語法**: 使用 `{鍵 值, ...}` 賦值，型別可自動判斷。
  - ```ucl
    $dic$ = {name "Alice", number "12345678"}
    $dic$[name]                       /* 獲取鍵 name 的值 ("Alice") */
    ```
- **型別持久性與外部交互**:
  - UCL 的型別系統在內部是持久且嚴格的。
  - 當與外部系統（如 CLI 輸出、檔案寫入）交互時，除非目標格式明確支援（例如 UCL 到 JS 的轉譯），否則型別資訊會被序列化為純文本，從而「丟失」其原始型別。

### **3. 階層設計與互動**

- 物件層次以 `.` 分隔，如 `Sys.Arch` 表示 `Sys` 物件下的 `Arch` 內容。
- 使用 `?` 可列印當前層次下可用的內容及其說明。
  - `?Sys` 會列出 `Sys` 下可用的成員（如 `Info`, `Clean` 等）。
  - `?WhatDay` 會顯示函式的簽名和說明文件。

### **4. 運算子**

- `{}` 進行**執行運算**。
- `[[]]` 進行**邏輯運算**。
  - UCL 的邏輯運算嚴格限制為二元操作。當存在多個邏輯條件時，它們會被由左至右依次計算並形成巢狀結構。例如，`A && B && C` 在內部會被解析為 `[[ A && B ]] && C`。
- `()` 進行**數學和規則運算**。

- **邏輯運算子**
  | 運算子 | 名稱 | 描述 |
  |:---:|:---|:---|
  | `===` | 邏輯相等 (Is Equal) | 判斷兩邊是否完全相等。 |
  | `!==` | 邏輯不等 (Is Not Equal) | 判斷兩邊是否不相等。 |
  | `>` | 大於 (Greater Than) | 判斷左邊是否大於右邊。 |
  | `<` | 小於 (Less Than) | 判斷左邊是否小於右邊。 |
  | `>=` | 大於或等於 | 判斷左邊是否大於或等於右邊。 |
  | `<=` | 小於或等於 | 判斷左邊是否小於或等於右邊。 |
  | `&&` | 邏輯且 (AND) | 當兩邊都為 `true` 時，結果為 `true`。 |
  | `||` | 邏輯或 (OR) | 當兩邊任意一邊為 `true` 時，結果為 `true`。 |
  | `^^` | 邏輯互斥或 (XOR) | 當兩邊有且僅有一個為 `true` 時，結果為 `true`。 |
  | `!` | **邏輯反向 (Invert)** | 一個抽象的「反向」運算子，用於反轉其後運算子的行為方向。例如，`!:=` 表示反向迭代賦值。它與 `!==` (不等) 中的 `!` 在概念上不同，後者僅為構成「不等」語意的一部分，而非獨立的反向操作。 |
  | `!>` | 反向大於 | 等同於 `<`。 |
  | `!<` | 反向小於 | 等同於 `>`。 |

- **賦值運算子**
  | 運算子 | 名稱 | 描述 |
  |:---:|:---|:---|
  | `:=` | **迭代賦值 (Iterative Assignment)** | 類似 `for...in`，將一個有序陣列的元素依序賦值給變量。 |
  | `!:=` | **反向迭代賦值 (Reverse Iterative Assignment)** | 從有序陣列的末尾開始，反向賦值。 |
  | `+=` `-=` `*=` `/=` `%=` `^=` | 複合賦值 | 執行數學運算後賦值。 |

- **數學運算子**: `+ - * / % ^ ..`
- **規則運算子**: `"datatime"` 可用符號 `1234567890+-`，從 `1970-01-01T00:00:00Z` 作為基準，允許單位 秒 分 時 日 月 年。

### **5. 控制流**

- `;`：作為換行符，用於分隔多個獨立的語句。
- `break`：完全退出當前的迴圈。
- `continue`：跳過當前迴圈的剩餘部分，並開始下一次迭代。

- **條件判斷 (if / or)**

  - `if [[]] ... or [[]] ... or ...` 當布林值為真才執行。
  - `|>` (邏輯然後): 若前方 `[[]]` 為 `true`，則執行後方 `{}`。

- **條件迴圈 (zo / @@)**

  - 當 `[[]]` 內的邏輯運算結果為 `true` 時執行 `{}` 區塊。

- **迭代賦值迴圈 (`:=` / `!:=`)**

  - `:=` 可用於遍歷一個有序陣列。當剩餘的元素不足以完成一次完整的賦值時，表達式將回傳 `false`，迴圈便會終止。
  - **範例:**
    ```ucl
    /* 每次迴圈，$i$ 和 $v$ 會被賦予陣列中連續的兩個元素。*/
    zo [[ $i$, $v$ := [1,2,4,8,16,32,64,128] ]] {
        Txt($i$, ",", $v$)
    }
    /* 輸出: 1,2; 2,4; 4,8; ...; 64,128 */
    ```

- **非同步控制流 (Asynchronous Control Flow)**
  - `wh` **(While/When - 監聽器)**: 用於監聽一個事件或狀態。當 `[[]]` 中的條件變為 `true` 時，執行其後的 `{}` 區塊。它與 `if` 的不同之處在於，`wh` 用於處理無法預測發生時機的事件。
    ```ucl
    wh [[ @Web.DOM.myButton === WebEvent::click ]] {
    	Log.Info("myButton 被按下")
    }
    ```
  - `dn` **(Done/Defer - 延遲執行)**: 定義一個延遲執行的 `{}` 區塊。無論當前的任務佇列是成功還是失敗，`dn` 區塊中的內容都將在所有任務執行完畢後執行。
    ```ucl
    dn { SCL.Clean("logfile") } /* 所有任務結束後，清理日誌文件 */
    ```

### **5. 函式 (Functions)**

- **結構與位置**:
  - 所有自定義函式都必須在一個 `物件 (Object)` 內部進行定義。
  - `Main()` 函式和內建函式庫（如 `Math()`, `Txt()`）是此規則的例外。
- **定義 (Definition)**:
  - 語法：`函式名(參數列表) -> (回傳型別列表) { ...函式主體... }`
- **執行與參數運算 (Execution & Parameter Evaluation)**:
  - **強制性參數運算**: 所有函式在執行時都**必須**使用 `()`，即使函式沒有參數。
  - **參數內優先運算**: 位於參數列表 `()` 內的任何表達式或函式呼叫，都會在傳遞給外部函式之前被優先運算。
- **範例：**

  ```ucl
  _What{
      Day(:any:) -> (:str:, :int:) { /* Day 函式位於 What 物件內 */
          /* ... */
      }
  }

  /* 函式執行與參數運算 */
  Main() /* 正確：即使沒有參數，也必須使用 () */
  Txt( Math.Pi(5) ) /* 正確：Math.Pi(5) 會先被運算，再傳遞給 Txt */
  ```

### **6. 高級語法 (SCLx)**

- SCLx 是 SCL 的底層表示，提供對程式更精確的控制。正常開發流程為 `SCL -> SCLx -> 編譯碼`。
- SCLx 不使用任何保留字，語法完全由符號構成。
- 它會為所有內容推導型別。
- 使用 `;;` 作為換行符與合併符，不依賴 `LF` 或 `CRLF`。
- 雖然提供了極致的控制力，但直接編寫 SCLx 的複雜度非常高。
- 高級語法的副檔名為 `.uclx`。
